# 云之家 DeepSeek Harness 插件

将个人云之家账号接入 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness)：在 Harness 侧栏打开聊天页面，Agent 可查询会话、读取消息、发送文字/图片/文件，也可自动处理指定会话的新消息并回传答复。

本分支是插件版本。Cordis Host/Client 插件管理连接生命周期、受保护的页面、Agent 工具和自动回复；已验证的云之家协议核心作为插件自动启动的本机 Python 服务复用，无需另外运行发送器。仍需 Python 3.9+，不需要云之家桌面客户端。独立网页模式也保留用于开发与兼容。

这是独立的非官方项目，与云之家及其运营方没有隶属关系。使用当前官方网页版内部接口，协议兼容性可能随上游更新变化。项目面向本机单用户使用，不支持直接部署为公网或多租户服务。

## 功能

- **聊天列表**：分页读取内部、外部会话，显示头像、最新消息摘要、时间、未读数、@ 提醒、置顶和免打扰状态；支持联系人与群组搜索。
- **实时同步**：上游 WebSocket 通知触发增量读取，本机 SSE 推送到浏览器；断线自动重连，并通过轮询补拉消息。
- **对话记录**：最近消息和向前分页、去重、撤回提示、已读状态、加载历史时保持位置；搜索当前已加载的消息。
- **消息展示**：文字、默认表情、富文本、图片/GIF、文件、语音、视频、引用和常见业务卡片；支持原图预览与下载。
- **消息发送**：文字、@ 群成员、图片和普通文件附件；支持粘贴、拖放和多附件队列；仅在取得服务端 `msgId` 后显示发送成功。
- **截图与 Markdown**：浏览器授权截图、区域裁剪并加入图片队列；Markdown 消息渲染、草稿预览和 `.md` 附件预览。
- **阅读与编辑**：按会话保存文字草稿、新消息提示、会话成员资料和窄屏布局。

## Harness 插件安装

已按官方 **0.2.1-alpha.2** 规范接入并验证；Harness 仍在预览期，其他版本需重新确认兼容性。Node.js 要求 `^22.19.0 || >=24.0.0`，另需 Python 3.9+。

在本项目目录中：

```sh
npm ci
npm run build
npm pack
```

在已安装 Harness 的环境中，将生成的源码包加入一个从 Web 模板创建的独立 profile（请使用包的实际绝对路径）：

```sh
dsh --profile yzj --from-default-profile web --dump-config
dsh plugin --profile yzj add /absolute/path/dsh-plugin-yunzhijia-0.1.3.tgz
dsh --profile yzj --no-open
```

打开 Harness 给出的登录链接，在侧栏点击“云之家”，用云之家手机 App 扫码。之后 UI 与 Agent 工具共享同一个网页登录会话。插件卸载或 Harness 退出会停止连接服务，重启后需要重新扫码。

自动回复默认关闭。开启时需要会话 ID 白名单；从 `yunzhijia_conversations` 工具取得 ID，按 [插件配置说明](docs/harness-plugin.md) 配置。群聊默认只回复 @ 提醒，单聊白名单内的新消息可直接触发。每个账号/会话使用独立 Agent，避免对话串线；初次连接不回答历史记录，过滤自己发送的消息。

自动回复使用 Harness 当前默认模型，生成的消息只回传到来源会话。文字以外的消息会提供附件名称，当前不自动读取附件内容或进行图像识别。原有工具仍可按用户要求主动发送图片和文件。

## 独立网页模式

### 环境要求

- Python **3.9 或更高版本**，使用标准库即可运行。
- 支持 JavaScript 模块、EventSource 和 sessionStorage 的现代浏览器。
- 已有个人云之家账号，以及可扫码登录的云之家手机 App。
- 本机网络能够访问云之家 HTTPS 和 WebSocket 服务。
- 独立网页模式运行不需要 Node.js；插件开发与完整测试需 Node.js 22.19+ 或 24+。

下载或克隆源码，进入项目根目录后启动：

```sh
python3 server.py
```

Windows 可使用 `py -3 server.py`。macOS 也可双击 `start.command` 或运行 `./start.command`；该脚本会尝试读取系统 HTTPS 代理配置。

打开 [本机聊天页面](http://127.0.0.1:8765)，点击“获取登录二维码”，用云之家手机 App 扫码并确认。登录后选择会话或搜索联系人，查看消息或发送文字、图片。

终端按 `Ctrl+C` 停止服务。重启服务后需要重新扫码登录。

### 配置

配置通过启动进程的环境变量传入；项目不会自动读取 `.env` 文件。

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `PORT` | `8765` | 本机 HTTP 端口；监听地址固定为 `127.0.0.1` |
| `YZJ_PROXY` | 空 | HTTPS 请求及 WebSocket 的 HTTP CONNECT 代理，例如 `http://127.0.0.1:7890`；端口需按本机配置修改 |

macOS / Linux 示例：

```sh
PORT=8766 python3 server.py
YZJ_PROXY=http://127.0.0.1:7890 python3 server.py
```

PowerShell 示例：

```powershell
$env:PORT = "8766"
py -3 server.py
```

修改端口后访问对应的 `http://127.0.0.1:<端口>`。直接启动 `server.py` 不会自动继承 macOS 系统代理，需显式设置 `YZJ_PROXY`。

## 图片发送机制

图片先上传到云之家文件服务取得 `fileId`，再通过附件消息 `msgType=8` 引用该文件。`param.ftype` 区分图片、GIF 和普通文件。完整字段与认证链路见 [消息发送实现说明](docs/message-implementation.md)。

| 情况 | 当前行为 |
| --- | --- |
| PNG、JPEG、GIF、BMP | 读取真实文件格式和尺寸，保留原始字节，不压缩或转换 |
| 单张图片超过 32 MiB | 拒绝上传 |
| GIF | 按 GIF/表情附件发送 |
| 其他图片达到 8 MiB，或任一边达到 5000 像素 | 按普通文件附件发送，界面提前提示 |
| 文字与多张图片 | 按顺序作为独立消息发送，不合并为混排富文本 |
| 上传或已知发送失败 | 保留失败项；已确认成功的图片移出队列 |
| 请求超时、回执缺失 | 标记结果不确定，阻止自动重发，允许核对近期消息 |

8 MiB / 5000 像素的分流规则来自桌面端观察，是本项目采用的保守设计；并非宣称当前官方网页或所有账号具有相同限制。核对最近 100 条消息未找到匹配记录不能证明发送失败，应在云之家确认后再决定是否重新发送。

## 输入框与 Markdown

| 工具 | 使用方式 |
| --- | --- |
| `@` | 群聊输入 `@` 或点击工具按钮，搜索成员；上下方向键选择，Enter 确认，Esc 关闭。提醒只针对明确选中的成员，编辑/删除其文字会取消该提醒 |
| 图片按钮 | 选择图片，或拖入、粘贴截图，加入待发送队列 |
| 文件按钮 | 选择普通附件，包括 PDF、Office、文本或 Markdown；单个文件暂限 32 MiB，保留原始字节；通过文件按钮选择的图片也按文件发送 |
| 截图按钮 | 浏览器授权选择屏幕、窗口或标签页，预览时拖动选择区域，再加入图片队列；不自动发送。取消或完成抓取后停止屏幕共享 |
| `M↓` | 开关当前草稿的 Markdown 预览；输入内容仍按原始文字发送，其他客户端是否渲染由其决定 |

文本消息识别常用 Markdown 标题、段落、列表/任务、引用、表格、代码块、行内代码、粗体/斜体/删除线和链接，并可切换原文。已有富文本消息优先保留上游结构。`.md` / `.markdown` 附件可在对话内打开预览，要求 UTF-8 编码且不超过 1 MiB；其他文件或更大的 Markdown 请下载查看。

Markdown 是常用语法子集，不承诺完整 CommonMark（例如嵌套列表未覆盖）。HTML 按文字显示，Markdown 中的远程图片仅提供链接，不自动加载。群聊 @ 使用成员 ID 和服务端校验；没有实现 `@所有人`。截图依赖浏览器、操作系统权限和屏幕共享能力，不支持时可使用系统截图后粘贴。

## 数据与使用边界

- 云之家登录 Cookie、二维码 token、会话缓存和发送回执保存在连接服务内存中，不主动写入磁盘或请求日志。退出登录会清理这些会话状态。
- 浏览器使用 HttpOnly、SameSite=Strict 的本机会话 Cookie。文字草稿及所选 @ 成员信息存于当前标签页的 `sessionStorage`，包含草稿内容和目标信息；退出登录清理草稿。浏览器会话恢复行为由浏览器决定。
- 图片发送队列不持久化；用户主动下载的文件会进入浏览器的下载位置。开发者自行录制的截图、HAR、日志和抓包文件可能包含私人消息或登录凭据。
- 插件页面使用 Harness 登录鉴权；内部连接服务额外使用每次启动生成的随机密钥，本机端口不接受普通浏览器直接访问。独立网页服务验证 Host 与写请求 Origin，上游连接校验 HTTPS 证书；媒体只转发来自已读取消息的受限云之家地址。
- 自动回复开启后，所选会话消息会交给 Harness 配置的模型，并按 Harness 自身规则写入会话历史；不再具有“所有消息只在内存中”的语义。模型服务的访问和数据保存方式由其配置决定。
- 默认表情从云之家公开 CDN 加载；原图、文件、卡片链接等依赖上游资源是否仍可访问。
- 特殊业务卡片主要提供内容展示与打开链接，不实现审批或提交动作。语音、视频播放还取决于浏览器编码支持。
- 发送回执去重记录只在当前服务进程内有效，不提供跨重启的持久幂等保证。不要将当前服务经端口转发、共享代理等方式暴露到公网。

项目开发期间已检查扫码登录、会话分页、实时连接、历史记录和 PNG 发送。在线检查仅覆盖有限账号和场景，不代表所有企业配置、媒体格式或网络异常均已验证。

## 常见问题

**二维码失效或出现 401**：重新获取二维码并扫码确认；服务重启、上游退出登录或会话过期均可能要求重新认证。

**实时连接失败但消息仍更新**：界面会退回自动同步。检查网络或代理是否允许访问上游 WebSocket；代理需支持 HTTP CONNECT。

**图片显示为文件**：这是上述尺寸/大小分流规则。项目不自动压缩原图。

**旧图片或附件无法打开**：上游文件可能已失效，也可能当前账号缺少访问权限；本机服务不能恢复已删除的文件。

**端口被占用**：停止已有实例，或通过 `PORT` 换一个端口，再访问对应地址。

**SSL 证书验证失败**：检查系统时钟、Python 证书环境和代理配置；不要通过关闭证书校验解决。
